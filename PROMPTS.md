# 5 промптов для работы с git через агента

## 1. Настроить git в папке
Настрой git в этой папке: включи git и создай .gitignore (обязательно .env и node_modules). Покажи, какие файлы попадут в первое сохранение, и подожди моего «ок». Потом сделай первое сохранение с подписью на русском, создай на GitHub приватный репозиторий и отправь туда.

## 2. Сохраниться перед задачей
Прежде чем начинать, сохрани текущее состояние проекта с подписью «перед: <что будем делать>».

## 3. Показать и сохранить изменения
Покажи простыми словами, что ты поменял и в каких файлах. Если я скажу «ок», сохрани с понятной подписью на русском и отправь на GitHub.

## 4. Откатить последнее изменение
Последнее изменение всё сломало. Откати его через git revert (не reset и не force push) и покажи, что вернулось.

## 5. Проверить на утечки
Проверь проект и всю историю сохранений: нет ли где-то ключей, токенов или паролей. Ничего не исправляй, сначала покажи, что нашёл.
