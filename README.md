# ☕ Набор для открытия кофейни

Готовые файлы от клуба NeuroMakers с урока «GitHub без страха». Забираете себе и сразу работаете.

## Как забрать
1. Нажмите зелёную кнопку **Use this template** → **Create a new repository**.
2. Назовите проект, например `kofeynya`, и нажмите **Create**.
3. Готово: у вас своя копия набора.

## Что внутри
- **index.html** — страница меню. Впишите название кофейни и свои напитки.
- **CLAUDE.md** — памятка для Claude Code: как аккуратно работать с вашим проектом.
- **AGENTS.md** — та же памятка для Codex.
- **.gitignore** — список файлов, которые не надо выкладывать в интернет. Например, файл с паролями.
- **PROMPTS.md** — 5 готовых фраз для ИИ-агента: «сохранись», «верни как было», «проверь, нет ли паролей» и другие.

## Как сделать сайт по ссылке
**Settings** → **Pages** → в поле Branch выберите `main` → **Save**. Через минуту меню откроется по адресу `ваш-ник.github.io/kofeynya`.

## Главное правило
Пароли и ключи не пишем прямо в код. Если всё-таки выложили — сразу удалите этот ключ там, где его получали, и сделайте новый.
