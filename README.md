# ☕ Набор для открытия кофейни

Стартовый набор клуба NeuroMakers с урока «GitHub без страха» (Песочница вайбкодера, 3 ноября 2026).

## Как забрать себе
1. Зелёная кнопка **Use this template** → **Create a new repository**.
2. Имя — например `kofeynya`. Выберите **Public**, если хотите бесплатный сайт по ссылке, или **Private**, если в проекте будут пароли и чужие данные.
3. Готово: у вас своя копия без чужой истории.

## Что внутри
| Файл | Зачем |
|---|---|
| `index.html` | Шаблон меню кофейни. Впишите название и свои напитки. |
| `CLAUDE.md` | Правила для Claude Code: сохраняйся перед большой задачей, не трогай секреты, без `push --force`. |
| `AGENTS.md` | Те же правила для Codex и других агентов. |
| `.gitignore` | Список «это в облако не отправлять». `.env` с ключами там уже стоит. |
| `PROMPTS.md` | 5 готовых промптов: настроить git, сохраниться, показать изменения, откатить, проверить на утечки. |

## Сайт по ссылке
**Settings** → **Pages** → Branch `main` → **Save**. Через минуту меню откроется по адресу `ваш-ник.github.io/имя-репозитория`.
GitHub Pages бесплатно работает только для публичных репозиториев.

## Главное правило
Ключи и пароли — только в `.env`, никогда в коде. Если ключ всё же попал на GitHub, удалите его там, где выдали, и сделайте новый: старая правка с ключом остаётся в истории.

Нашли что-то полезное для набора — присылайте ведущему, добавим.
